## Application rules
- Use TanStack Start with one cinematic film homepage and in-page section anchors; preserve the template router.
- Keep film content and image references in a browser-safe data module so promotional copy is easy to maintain.
- Define cinematic styling in the global token system and shared Button variants to keep visual treatments consistent.
- Newsletter visitors have insert-only access; never expose subscriber emails through public reads.
- Clearly distinguish the fictional film's concept trailer and promotional reviews from actual released media and publications.
